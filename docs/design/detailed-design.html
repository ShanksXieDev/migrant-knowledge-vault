分层与进程架构

依赖方向铁律：UI → Cordis → 插件 → Tauri IPC → Rust 壳；反向只允许事件。Rust 壳是唯一持有系统权限的一层。

fig-08-flow.svg下载 SVG

WebView 渲染进程

半可信：UI + Cordis + 插件。只能通过 IPC 调用系统能力，不得直接触碰文件系统、启动进程或联网。

Rust 壳（Tauri 2）

完全可信：受限 fs、notify 监听、子进程、SQLite FTS5、Git。所有路径经工作区作用域校验。

进程外组件

OnlyOffice DS：127.0.0.1:port + JWT 回调；崩溃自动重启，连续失败降级为外部唤起。

Cordis Host / Client 拆分

两侧各自 declare module 'cordis' 扩展同一 Context 接口，避免类型冲突。

Git 集成

能力实现策略
状态git_status仅工作区作用域，默认忽略 .index/
提交git_commit文档区 Ctrl+S = 保存；工作区 = 提交面板（见 D-8）
自动快照调度器 + 空闲检测默认 10 分钟或空闲 60s；跳过仅索引变动
日志git_log + commits 缓存首次全量，之后增量
diffgit_diff文本逐行；二进制给结构化摘要
回滚git_restore生成新提交而非 reset，历史不丢
远端可选默认无 remote，离线可用

插件运行时与安全

项要求
路径所有 fs 命令经 normalize + starts_with(workspace) 校验；拒绝 ..、符号链接越界、UNC 越权，越界返回 E_SCOPE
静态服务插件内置 web 包走 127.0.0.1 微型静态服务，必须带一次性 token，并做路径穿越防护
权限声明清单声明 fs:read / fs:write / net / proc，安装时展示并由用户确认，net 默认拒绝
隔离插件异常不扩散；崩溃写隔离日志；sidecar 崩溃自动重启
数据外流无出网路径；未来开启也仅限插件更新检查与可选 Git remote
供应链记录来源、版本、SHA-256；未知来源插件显著提示

故障检测降级用户可见

Git 冲突git_status 报冲突暂停自动快照标题栏冲突徽标

性能预算与可观测性

需求设计位置验收方式
本地优先（离线可用、不降级）系统上下文 / 安全断网启动与全流程走查
文件优先（原生文件可被外部工具打开）格式数据流外部 Office / 文本工具直接打开库内文件
Git 优先（索引与本体分离、可重建）索引表 / Git 集成删除 .index/ 后一键重建成功
P0 全文检索 + 命中跳转抽取管线 / SearchService1 万文档 < 500ms；点击命中定位到锚点
P0 双链 + 反链 + 图谱core:link / LinkService建链→反链出现→图谱呈现→失效标记
P0 Git 版本core:git / git_*自动快照 / 手动提交 / diff / 回滚四步闭环
可观测事件总线 / 降级矩阵索引重建与 Git 操作均有进度与失败提示
安全路径沙箱路径穿越用例全部被 E_SCOPE 拒绝

风险与待决项

以下 11 项为两份输入文档之间（或与工程现状之间）的不一致，需评审后落 ADR。

#问题影响建议建议 ADR

D-2索引位置冲突：需求要求随库存于 .index/，架构要求存 app data可移植性与性能不可兼得双层策略：JSONL 快照 + SQLite 缓存ADR-0005
