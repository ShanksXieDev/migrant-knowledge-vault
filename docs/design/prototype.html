全局骨架

标题栏常驻分支与提交状态；左栏 240–320px；中栏标签页 + 文档区；右栏 280–360px 随选中项联动；状态栏常驻索引 / Git / 插件 / 扫描四类状态。

P-1 工作台（默认首屏）

一屏完成「找文件 → 看内容 → 追关系 → 存版本」。

p01-workbench.svg下载 SVG
  • ① 资源侧栏：统一文件树，支持过滤、右键、拖拽插入引用
  • ② 跨格式引用条：源变更时提示「已变更」，可刷新/看差异
  • ③ 文档工作区：预览 = 编辑同页，渲染器按格式分发
  • ④ 能力条：模式、引擎、导出/另存；引擎缺失即禁用
  • ⑤ 上下文面板：大纲 / 反链 / 引用 / 修订 四页签联动

页面原型

以下 10 个页面与主工作台共同覆盖需求 §3 P0/P1 全部能力面。

P-2 文件树侧栏

统一知识入口：所有格式在同一个树里，拖拽即生成引用。

p02-file-tree.svg下载 SVG
  • 单一入口管理多格式文件：md / xlsx / pptx / docx / docxxml / base / pdf / drawio / vsdx
  • 拖拽文件到文档区生成「动态引用」而非复制内容
  • 输入 [[ 触发三级补全：文件 → 标题 → 块锚点

P-3 文档工作区（预览 = 编辑同页）

统一容器按格式分发渲染器；能力不足即降级，布局不变。

p03-document-workspace.svg下载 SVG
  • 一个容器承载全部格式，切换格式不改变布局（需求 §5.4）
  • 编辑块、代码块、标题均可作为双链锚点
  • 引擎缺失 → 占位卡，引用条与反链仍可用

P-4 跨格式引用条

引用是动态的：源变更即标记，可刷新 / 看差异 / 重定位。

p04-reference-bar.svg下载 SVG
  • 引用是动态的，不是复制：源更新即标记「已变更」
  • 刷新 = 取源最新内容写回引用处，产生一次可 diff 的变更
  • 失效（源删除/改名）→ 提供「重定位」与「转为纯文本快照」两个出口

P-5 搜索中心

跨格式全文检索 + 上下文片段 + 多维过滤，点击命中跳转原文精确位置。

p05-search.svg下载 SVG
  • 命中列表带上下文片段，命中词高亮（Blue 450）
  • 过滤（格式/标签/路径/时间）与检索同一表达式下推
  • 点击命中 → 打开文档定位 → 右栏自动切到「反链」形成闭环

P-6 内联双链与反链面板

双链语法、反链条目与失效分组；搜到 → 跳转 → 看反链 → 顺藤摸瓜。

p06-backlinks.svg下载 SVG
  • 双链语法：`[[文档#锚点]]`、`@引用`、引擎生成的引用块
  • 反链条目携带上下文句与 Git 状态，便于判断新鲜度
  • 失效链接单独归组，提供「重定位」出口

P-7 关系图谱视图

节点=文档，边=引用关系；默认 2 度邻域保护渲染性能。

p07-graph.svg下载 SVG
  • 节点 = 文档，边 = 引用关系（区分单向 / 互引 / 失效）
  • 默认只展开 2 度邻域，避免万级节点一次性渲染
  • 双链关系图与反链面板共享同一关系数据

P-8 Git 时间线与 diff

自动快照与手动提交共用时间线；二进制给结构化 diff；回滚生成新提交。

p08-git-timeline.svg下载 SVG
  • 自动快照 + 手动提交共用一条时间线，标注提交类型
  • 二进制文件给结构化摘要（工作表/单元格/页/版式）
  • 回滚生成新提交，保留完整历史

P-9 命令面板

统一入口：文件 / 命令 / 插件 / 设置项四类候选聚合。

p09-command-palette.svg下载 SVG
  • 统一入口：文件、命令、插件安装、设置项四类候选
  • 插件与设置项为 P1 动态注册来源
  • 快捷键直选（Ctrl+1..9）用于高频动作

P-10 设置（插件与格式能力）

插件清单即能力清单；未安装与实验性插件显式标注。

p10-settings.svg下载 SVG
  • 插件清单即能力清单：格式 → 能力 → 状态 → 操作
  • 未安装/实验性插件在能力表中显式标注
  • 安装时展示权限声明（fs / net / proc），net 默认拒绝

P-11 降级与异常态

降级不阻断：占位卡保留引用与反链链路，只读提供「另存副本」。

p11-degraded-states.svg下载 SVG
  • 降级不阻断：占位卡保留引用与反链链路
  • 只读与占用场景提供「另存副本」出口
  • 索引重建期间搜索结果标注覆盖范围

页面状态矩阵

页面空态加载态错误态只读 / 降级
工作台未打开知识库 → 选择文件夹 / 新建骨架屏（文件树 + 文档区）库路径不可读插件缺失 → 占位卡
文件树无文件 → 新建 / 导入懒加载子树目录读取失败部分子目录不可读
文档区未选择文档 → 引导渲染骨架解析失败 → 降级为纯文本只读横幅
搜索无查询词 → 提示与最近搜索结果流式追加索引不可用 → 重建引导部分格式未索引（明示覆盖范围）
反链无引用 → 尚无双链—关系数据损坏 → 重建索引失效链接单独归组
图谱无关系 → 引导创建引用渐进渲染规模超限 → 降深度过滤后为空
时间线非 Git 仓库 → 初始化引导载入提交中Git 冲突 / 锁无 remote 时仅本地
