# 本地个人知识库 · 需求描述

> 版本：v1.0

---

## 0. 一句话定位

**项目名称：**&#x4D;igrant Knowledge Vault

一个 **本地优先、文件优先、Git 优先** 的个人知识底座：统一管理 / 检索 / 预览 / 编辑多格式文档，并以「双向链接（双链）+ 全文检索」驱动知识资产的有效联动。

---

## 1. 设计原则（三优先，不可妥协）

| 原则                     | 含义               | 落地约束                                                                   |
| ---------------------- | ---------------- | ---------------------------------------------------------------------- |
| **本地优先** (Local-first) | 数据 100% 落本地，离线可用 | 无云端强依赖；隐私与数据主权归用户；断网功能不降级                                              |
| **文件优先** (File-first)  | 知识以原生文件落盘        | 不锁进专有数据库；`.xlsx / .pptx / .docx / .docxxml / .base` 可被任意工具直接打开、迁移 |
| **Git 优先** (Git-first) | 版本与同步基于 Git 仓库   | 天然获得历史回溯、diff、分支、多端同步能力；索引随库储存但置于独立 `.index/` 目录，与知识本体分离、可重建         |

---

## 2. 目标用户与典型场景

- **用户**：个人知识工作者
- **场景**：
  - 把散落在各处的笔记、台账、方案、文档、框图集中到一个可检索的"第二大脑"
  - 写 Markdown 时 `@` 引用 Excel 台账的某个单元格、PPT 的某一页、Drawio 的某个节点
  - 通过全文检索 + 双链反查，快速定位"哪些文档引用了我正在看的东西"
  - 用 Git 管理知识演进，可回溯任意历史版本、对比差异

---

## 3. 核心能力清单（按优先级）

### P0 — MVP（首版必须交付）

- **统一知识入口**：单一界面导入/管理本地文件夹，Git 初始化即知识库
- **全文检索**：跨所有格式的内容检索，命中可跳转原文位置
- **多格式预览**：八种格式均可原地预览（见 §4 矩阵）
- **Markdown 双链**：正向链接 + 反向链接（Backlink）+ 基础关系图谱
- **Git 版本**：自动/手动提交、历史回溯、diff 对比

### P1 — 增强

- **文档插入与跨格式引用**：在任一文档中插入/引用其他文档的片段（页、单元格、节点级）
- **标签 / 元数据检索**：按标签、类型、时间、来源多维过滤
- **二进制格式编辑：外部唤起 + 可独立更新的编辑器插件**（决策 D1 已按 v3 修订：宿主不内置编辑器与文本抽取，6 个编辑器插件 + 1 个只读抽取适配器均为运行时动态库）

### P2 — 远期

- **关系图谱可视化**：双链关系图交互浏览、聚类（已落地，见 `README.md` §13.5）
- **Visio / Drawio 节点级引用**：点击流程图节点跳转到引用它的文档（已落地，见 `README.md` §13.8）
- **高级检索**：正则检索（已落地，见 `README.md` §13.9）；语义 / 向量检索暂不实现，纳入远期规划（可后续接本地大模型）

## 5. 关键功能详述

### 5.1 双链系统

- 文档间通过 `[[文档名]]` 或 `@引用` 建立链接
- 每个节点自动维护**反向链接列表**（谁引用了我）
- Markdown 支持块级双链（标题 / 代码块 / 列表项锚点）
- 提供关系图谱视图，可视化节点关联

### 5.2 检索引擎

- 全文索引：标题 + 正文 + 文档内嵌文本（Excel 文本、PPT 文字、Word 正文）
- 检索结果展示命中上下文，点击跳转原文精确位置
- 支持过滤：格式、标签、路径、时间范围

### 5.3 文档插入与联动

- 支持在文档中**嵌入/引用**其他文档片段（非复制，而是动态引用）
- 被引用内容更新时，引用处可同步刷新或标记"已变更"
- 搜索结果与双链双向打通：搜到 → 跳转 → 看反链 → 顺藤摸瓜

### 5.4 预览体系

- 统一预览和编辑容器，按格式分发渲染器

### 5.5 Git 版本

- 知识库根目录即 Git 仓库
- 自动快照（可配频率）+ 手动提交（Ctrl+S）
- 时间线浏览、版本 diff、一键回滚

## 6. 非功能性需求

| 维度      | 指标（建议基线，可按实际调整）                                    |
| ------- | -------------------------------------------------- |
| **性能**  | 1 万文档规模下全文检索 < 500ms；应用冷启动 < 2s；定时扫描磁盘新增内容（单独进程）                    |
| **可移植** | 整个知识库 = 一个文件夹（含 `.index/` 索引目录），整体复制即可迁移；索引可一键重建 |
| **兼容**  | 支持 Windows                        |
| **安全**  | 本地加密存储可选；Git remote 可选私有仓库；不上传任何内容至第三方             |
| **可观测** | 索引重建、Git 操作有进度与失败提示                                |

## 7. 范围边界

**明确不做（防范围蔓延）：**

- 多人在线实时协同编辑（超出本地优先定位）
- 云端 SaaS 化、账号体系
- **Web / 浏览器端**

**可后续扩展：**

- 语义 / 向量检索、本地 LLM 问答（**暂不实现，纳入远期规划**）
- 多端 Git 同步（已有 Git 基础，自然演进）
